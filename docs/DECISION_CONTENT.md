# 决策内容的生成、校验与展示

0.14.2 将模型内容与展示模板分开：模型生成 decision-content.v1 结构化候选，程序校验后保存，固定模板派生聊天内的原生问题卡。

## 使用体验

问题区域只显示一个问题；每个选项显示方案名称、具体后果、推荐标记和有依据的风险。组件已有序号时不再重复 A/B。产品影响和推荐理由保存在详情中，用户需要时再解释，不默认堆叠说明。

用户选择所必需的行为范围和限制仍须放在选项中，不能为了简短只放进详情。确认来源、选择身份和冻结版本的核验保持不变，展示或预选不产生确认。

## 内容约束

新 MCP 提取/提议修订要求 content_version=decision-content.v1。具体可用字段与长度以该入口的 inputSchema 为准。程序拒绝空白、超长、多段格式、重复选项、重复编号、推荐状态不匹配和风险评估矛盾；返回 CONTENT_REPAIR_REQUIRED 及字段和修正要求。模型须保留实质后果重新生成，不能机械截断。

每个选项用 risk_assessment 声明 not_assessed / no_specific_risk / risks_identified。没有风险字段不再默认为无风险；旧卡缺少评估时只在详情标为未评估，不回写历史。

具体风险的 low / medium / high 均可显示。potential 必须有触发条件和推断理由；observed 必须引用真实、当前的资料。新内容依据不成立时要求补查，不隐藏警告后继续生成可激活卡。

## 验证边界

格式与引用核验不证明推荐合理、风险完整或项目绝对安全。风险严重性、适用范围、条件是否现实与产品含义仍由当前模型结合资料判断，不新增自动业务分类器或独立认证。

旧账本仍可读、旧卡可接续。更新运行包与插件后重新连接 MCP，才能同时加载新的生成指引和固定模板；历史聊天中的卡不会被改写。
