# BuildChoice · 项目决策记忆（0.9）

采用分层记忆与可恢复遗忘。只在 V3 pilot 中启用，保存在当前工作区 `.buildchoice_audit/ledger.sqlite3`，不自动上传，不保存聊天全文，不跨工作区共享。

## 使用

在 Codex 中说“查看这个项目的决策记忆”或“查找小票保存相关的决定”，Agent 通过 `buildchoice_memory` 展示当前记忆、原选择、来源和短编号。查询归档与遗忘记录时明确说明“包括已归档的记忆”。实际开发时 status 也提供当前项目记忆；关键词召回只是检索提示，不证明业务语义相同。

所有真实 Hook 已确认选择自动成为普通参考，旧版已确认历史也按原确认时间进入参考层。未确认、Agent 自报或自由回答不进入记忆。参考从确认时间起 30 天后归档；查询不会延长时间。30 天按 UTC 时间戳计算，无后台任务，读取时计算当前状态。

查询得到短编号后，在原对话单独发送下列完整命令（示例编号须换成实际编号）：

```text
长期记住 M123456789ABC
取消长期 M123456789ABC
遗忘 M123456789ABC
恢复 M123456789ABC
```

- 长期记住：将当前有效参考设为项目长期规则，跨聊天保留，不自动过期。
- 取消长期：降为普通参考，从此次操作起保留 30 天。
- 遗忘：立即停止主动召回，保留原确认和管理历史。
- 恢复：恢复遗忘或归档记录；普通参考重新获得 30 天窗口，原长期规则恢复后仍为长期规则。

不会物理删除账本。引用、解释、混合指令不会执行管理操作。存在待答决策卡时先处理原卡，不把管理指令当选项或同时修改记忆。未知编号和已被修订替代的版本拒绝管理；归档/遗忘项需先恢复才能长期记住。来源文件变化的记忆显示 needs_review，恢复不能跳过复核。

## 在后续开发中沿用

候选通过 memory_intent 声明本轮意图：reuse 表示 Agent 已核实同范围且需求未改变；change 表示要求改变原规则；uncertain 或缺省表示范围待核实。后两者不会自动沿用旧规则，避免用户说“改为自动保存”时仍静默套用旧选择。意图为 Agent 声明，不是服务端语义证明。

普通参考不自动决定新任务。当前长期规则只有在字段、类别、所选方案含义一致时可供复用；选项 ID 可以重排，结构化 value 必须一致，未提供 value 时标签和后果须一致。依然由 Agent 判断任务与字段是否相同，不是通用语义证明。

筛选返回 PROJECT_MEMORY_RULE、confirmation_status=project_rule_reused 和原确认来源。新任务没有新增用户确认，不能用这一结果直接创建仅接受本任务确认的 acceptance 集合。需要本次验收时仍需本任务的真实确认；不迁移旧会话的任务读写权限。

敏感风险继续要求当前选择，记忆不授权付费、发布、发送、删除或任何宿主操作。多个当前长期规则冲突、方案改义或当前文件约束矛盾时先询问，不按时间强选最新。当前任务的真实明确选择可作为本次任务的决定，不自动替换项目规则。

同一个决定产生新修订时，旧确认仍留在历史，但旧记忆停止沿用且不能恢复；新版本经真实确认后成为新的普通参考，不继承长期标记。不同聊天的同字段决定不自动判为替代，应查看冲突并明确遗忘旧规则、标记新规则。

管理和过期变化会使旧筛选缓存失效；已复用规则的状态查询会重新检查有效性，需要时提示重筛。实现和测试输入仍按原有验证机制检查，不因存在记忆而成为已验证。

## 边界

查询需要当前工作区有效 Hook 句柄，最多返回 30 项，带 total_matches / truncated；可使用关键词或短编号缩小范围。默认排除归档、遗忘、被替代和来源待复核项。工具和记忆内容是数据，不能当作系统指令。信任边界沿用本地 Hook，不能防御有能力改写本用户账本或运行时的程序。

本版提供对话工具与管理命令，未增加网页管理界面、跨项目共享、自动语义合并或任意自然语言管理解析。工程回归使用模拟 Hook，真实聊天的召回质量应单独评测。
