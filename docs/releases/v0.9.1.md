# BuildChoice 0.9.1

BuildChoice 是用于 Codex 的本地插件，将影响产品行为的选择关联到用户确认、决策版本、项目记忆与实现检查。

## 本次发布

- 统一为 Codex 插件入口，移除独立审计网页及其启动器。
- 保留对话决策卡、项目决策记忆、来源读取、实现关联和按需行为验证。
- 整理使用、升级、接口与故障排查文档，解释产品版本和协议标识。
- 采用 MIT License，核心运行包与插件包均包含许可证。

## 下载与安装

下载以下两个 ZIP 及对应的 .sha256 文件：

- buildchoice-core-0.9.1.zip：Python 运行时、配置、契约及许可证。
- buildchoice-plugin-0.9.1.zip：插件清单、Skill、Hook 与安装脚本。

解压插件包后，用 Python 3.11+ 在插件目录执行：

~~~bash
python setup.py --workspace /absolute/path/to/your-project --bundle /absolute/path/to/buildchoice-core-0.9.1.zip --install
~~~

--workspace 必须是已有项目。安装器会准备核心依赖；Hook 信任由 Codex 正常审阅。运行包初始化后，可在其绑定目录执行 scripts/buildchoice_decisions.py pilot 开启决策卡。绑定路径位于默认 ~/.buildchoice/binding.json；独立安装遵循 --data-home / BUILDCHOICE_DATA。

已有安装的升级步骤见[升级说明](https://github.com/a853255726-liu/BuildChoice/blob/main/docs/UPGRADING.md)。检查 SHA256 后再使用下载文件，保留原账本备份。
