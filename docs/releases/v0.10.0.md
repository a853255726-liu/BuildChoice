# BuildChoice 0.10.0

- 安装时生成独立插件副本，不改写源码中的 MCP 和 Hook 配置。
- 支持多个项目绑定、独立运行设置及活动项目切换。
- 选项确认支持字母、序号、完整方案名称和明确的自然语言表达。
- 记忆检索使用中文词组/双字片段、英文词与稳定标识，支持 decision_key 和 option_key。
- 整理首页、使用指南及接口说明。

下载核心运行包、插件包及各自 SHA256 文件。在解压后的插件目录使用 Python 3.11+：

~~~bash
python setup.py --workspace /absolute/project --bundle /absolute/buildchoice-core-0.10.0.zip --decision-mode pilot --install
~~~

已有用户先备份项目账本，重新初始化并安装，再重新连接 MCP。项目切换和升级方式见[项目指南](https://github.com/a853255726-liu/BuildChoice/blob/main/docs/PROJECTS.md)及[升级说明](https://github.com/a853255726-liu/BuildChoice/blob/main/docs/UPGRADING.md)。
