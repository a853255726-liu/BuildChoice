# 界面内容与交互

制作、修改、检查或审阅相关用户界面时使用；普通无关代码维护不加载。不规定网页栈、视觉风格或截图工具。

<!-- buildchoice-guidance:topic:interface:start -->
维护版本：`intent-alignment.v1`。

沿与用户任务相关的完整操作路径看可见文案、信息层级、控件与结果：能否理解下一步、完成操作并辨认结果，注意力是否被引向无关事项。背景、真实限制与必要披露分别判断其作用和强调程度；不按词语判错、不规定固定审美。源码／结构只能支持对应结论，实际视觉使用已有画面或合适工具，截图不是前置条件。
<!-- buildchoice-guidance:topic:interface:end -->

制作时先确定主要操作和它所需的信息，再安排标题、控件、空状态与成功／失败提示；每处内容有具体作用，用用户能理解的概念命名。交付前沿一条相关操作路径检查，不遍历无关页面或增加设计认可。

文字和路径可从源码或控件结构查，实际视觉判断使用已有画面或合适工具；没有画面就限定结论。真实数据、权限和运行约束必须保留；是否展示、位置及强调程度依据用户理解和操作所需，不自动把开发过程或工具说明搬入产品，也不按词删掉用户明确要求的教学、演示或必要披露。

本专题辅助生成与检查，不构成完整体验审阅或目标一致性证明；正式流程沿用原入口。

改写自 Anthropic frontend-design 的用户视角文案与有目的的设计原则；移除了固定审美、网页栈倾向及强制视觉检查。见[来源、版本与许可证](upstream-sources.md)。
